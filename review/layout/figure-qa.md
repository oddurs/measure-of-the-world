A blocker is a text/text collision deeper than 1.5pt in both axes, or type that prints below 7.0pt. Printed size is the drawn point size times `(width_frac x 4.5in) / saved_png_width_in`, using the tight-cropped width that `savefig(bbox_inches='tight')` actually writes.

Each font row names where the text came from: `text` for an `ax.text`/`annotate` call, `legend` for a legend entry, `title`, `xlabel`/`ylabel`, `xtick`/`ytick`. A `legend` or `title` row drawn at a round size (8, 9, 10pt) has bypassed `common.PRINT_FONT_SCALE`, which only reaches sizes set through `Text.set_fontsize`.

An overlap between two rotated labels is reported as a WARN, not a BLOCKER: window extents are axis aligned, so a rotated pair can be flagged when the glyphs do not actually touch.
